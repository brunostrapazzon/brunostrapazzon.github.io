NetDoctor · network diagnosis with verifiable AI

Personal project · 2026 · github.com/brunostrapazzon/NetDoctor

  • Automated the triage of “my internet isn’t working” tickets: a Windows app that tests the connection in about 10 seconds and explains the cause in plain Portuguese, with a client report and a technical report for support staff.
  • Diagnosis by deterministic rules with 10 possible outcomes; the language model (Groq, OpenAI or local Ollama) only rewrites the explanation and never decides.
  • Validated AI output (format, 1 to 3 actions, length limit), with automatic fallback to built-in offline text on error, timeout or invalid response.
  • Privacy enforced by tests: the AI receives only a closed list of fields; network name, IPs and MAC never leave the machine.
  • 279 automated tests on real Windows output in Portuguese and English; a GitHub Actions CI/CD pipeline tests, builds the executable (PyInstaller) and publishes the release.
